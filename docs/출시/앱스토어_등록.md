## 2. 운영 서버 — 올렸다 (2026-09-11)

Railway 프로젝트 `nolmeongbopseo` (사용자의 기존 Hobby 계정). 무료 주소
`https://nolmeongbopseo-production.up.railway.app`, 출시용 앱은 `ios/project.yml` 의 `API_BASE_URL` 로 이 주소를 부른다.

- 환경변수 `KTO_API_KEY`, `TYPECAST_API_KEY`
- 볼륨 `/app/storage/tts_cache` — 음성 캐시가 배포마다 지워지지 않는다
- **음성 시드** `storage/tts_seed/` — 개발 기기에서 만든 Toby 음성 31줄을 이미지에 싣는다. 첫 배포 날 Typecast
  크레딧이 바닥나 운영에서 합성이 막혔기 때문이다. 대사나 목소리를 바꾸면: 크레딧 확보 →
  `backend/scripts/warm_play_lines.py` → 새 파일을 `tts_seed` 로 복사 → `railway up`
- 다시 배포: 저장소 루트에서 `railway up --detach`
