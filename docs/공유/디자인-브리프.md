# 놀멍봅서 — 디자인 브리프

> 외부 협업(디자인 AI·외주)에 그대로 붙여넣는 문서다. **비밀정보는 절대 넣지 않는다** — 심사용 계정 ID/PW, API 키, Firebase 설정. 원본 설계 문서를 통째로 복사하지 말 것.

---

## 1. 이 서비스가 뭔가

**놀멍봅서** — 제주어로 "천천히 보세요". 제주를 방문한 소규모 여행자를 위한 iOS 앱.

**한 줄:** 전문 가이드 없이는 관광지를 깊이 경험하기 어려운 문제를, **현장 참여형 AI 스토리 경험**으로 푼다. 정보가 아니라 **경험**을 판다.

**문제:** 전문 가이드는 비싸고, 단체 가이드는 내 속도·관심사에 안 맞는다. 결국 그 장소의 역사·이야기·맥락을 모른 채 사진만 찍고 떠난다.

**차별점 (가장 중요):** 오디오 가이드 앱들은 준비된 해설을 **일방향으로 재생**한다. 놀멍봅서는 **현장에서 사용자에게 묻고, 그 대답에 따라 다음 대사가 갈린다.** 그리고 눈앞의 무엇을 볼지 짚어주고, 알고 난 뒤 **다시 보게** 만든다.

**비즈니스 모델**
- 무료: 검증된 여행 코스 추천 (사용자를 끌어들이는 훅)
- 유료: 장소 1곳의 현장 스토리 경험 — 5,000원 이하, 90일 이용

**v1 범위:** 유료 콘텐츠는 **성산일출봉 1곳뿐이다.** 여러 곳을 얕게 만들지 않고 한 곳을 압도적으로 만든다.

## 2. 디자인의 북극성 ★ 가장 중요한 제약

> **사용자가 폰을 적게 보게 만든다. 눈은 풍경에 있어야 한다.**

이게 모든 디자인 결정을 지배한다.

- 오디오 내레이션이 **코어**다. 화면은 보조다.
- **이야기 재생 중 화면에는 요소를 3개만 둔다** — 재생/멈춤 · 참고사진 · 다음 지점. 장식 금지.
- 반대로 **화면을 봐도 되는 구간**(홈, 장소 고르기, 진행도, 결제, 완료 기록)은 마음껏 꾸민다.

디자인이 예뻐서 사용자가 화면을 계속 들여다보게 되면, 그건 **실패**다.

## 3. 미감 — 픽셀아트 + 실사 사진

> 픽셀아트로 만든 게임 같은 앱 안에, 제주의 실제 풍경 사진이 들어앉는다.

**색감 방향: 제주 파스텔 픽셀.** 밝고 부드러운 제주 자연색이라 실사 사진과 채도가 비슷해 서로 튀지 않는다.

레퍼런스는 둘 — **싸다구카페/픽셀 도트 세계관**에서 보이는 방식을, **투어라이브(오디오 가이드 앱)** 에서 화면 구조와 정보 배치를 가져온다.

### 절대 규칙 — 픽셀과 실사의 경계

| 픽셀아트로 만든다 | 실사 사진 그대로 둔다 |
|---|---|
| UI 셸 — 프레임·버튼·아이콘·진행바·잠금 배지·탭바 | 장소 사진, 카드 썸네일, 커버 |
| 가이드 캐릭터, 배경, 홈 세계관 | **참고사진** (시선 유도용) |
| 지도 마커·핀, 참고사진 위의 표시 마커 | |

**사진에 픽셀 필터를 씌우면 안 된다.** 성산의 절벽과 분화구는 실제로 보여야 한다. 도트로 바꾸면 "저것을 보세요"라는 안내가 무의미해진다. 사진은 원본 그대로, **픽셀 테두리 프레임 안에** 넣는다. 이 대비가 오히려 컨셉을 선명하게 만든다.

### 색 (라이트 / 다크 — 두 모드 모두 필수)

새벽 일출이나 저녁에 현장에서 쓰는 앱이라 다크 모드 사용이 실제로 잦다.

| 역할 | 라이트 | 다크 | 쓰는 곳 |
|---|---|---|---|
| 배경 | `#F4EFE4` | `#14181A` | 화면 바탕 (모래빛) |
| 표면 | `#FFFFFF` | `#1E2427` | 카드·시트 |
| 잉크 | `#1E1B18` | `#EDE7DC` | 본문·테두리 (현무암) |
| 잉크 약함 | `#6B635A` | `#9A9187` | 보조 설명·비활성 |
| **주색** | `#1E6F6B` | `#4FB3AD` | 주요 버튼·선택 상태 (성산 앞바다) |
| **강조** | `#F2B233` | `#FFC759` | CTA·무료 배지·진행 완료 (유채) |
| 잠김 | `#C9503C` | `#E0705A` | 잠금 배지·경고 (화산 적갈) |
| 완료 | `#4E8C3F` | `#6FAE5E` | 들은 이야기 표시 (억새) |

**이 팔레트 밖의 색을 쓰지 않는다.** 픽셀아트는 색 수가 적을 때 좋아 보인다.

- 그라디언트 금지. 단색 면으로 구성한다.
- 반투명 최소화.
- **색만으로 상태를 구분하지 않는다** — 잠김은 색 + 자물쇠 모양, 완료는 색 + 체크 모양을 함께 쓴다.

⚠️ **밝은 배지 배경(강조·잠김·완료) 위의 글자는 다크 모드에서도 어두운색(`#1E1B18`)으로 고정한다.** 다크 모드 잉크를 강조색 위에 올리면 명도 대비가 1.26:1이 되어 글자가 사라진다. 실제로 겪은 문제다.

### 글자

**갈무리(Galmuri)** — 닌텐도 DS 폰트에서 영감받은 한글 픽셀 폰트. SIL 오픈 폰트 라이선스 1.1이라 상업적 이용 가능.

비트맵 폰트라 **설계 픽셀 높이의 정수배**로만 선명하다. 어중간한 크기는 흐려진다. 그래서 크기를 임의로 정하지 않는다.

| 용도 | 폰트 | 크기 |
|---|---|---|
| 화면 제목 / 카드 제목 / 본문 / 버튼 | Galmuri11 | 22 (11×2) |
| 작은 설명·배지 | Galmuri9 | 18 (9×2) |
| 숫자 강조 (시간·가격) | Galmuri14 | 28 (14×2) |

**긴 글에는 픽셀 폰트를 쓰지 않는다** — 이야기 스크립트 전문, 약관, 오류 상세는 시스템 폰트(Apple SD Gothic Neo). 눈이 빨리 피로해진다. 프레임과 버튼은 여전히 픽셀이고 안쪽 글만 읽기 편한 폰트다.

### 여백과 모양

- **모든 간격은 4의 배수:** 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64
- 카드 안쪽 16 · 카드 사이 12 · 섹션 사이 32 · 화면 좌우 16 · 버튼 높이 48 · 탭바 높이 56
- **모서리 반경은 0이다. 예외 없다.** 둥근 모서리는 픽셀아트를 즉시 깨뜨린다.
- 테두리는 잉크색 실선 — 버튼·입력창·배지 2px, 카드·시트·모달 3px
- **그림자는 번지지 않는다.** 어긋난 단색 그림자: `x +3, y +3, blur 0, 색 잉크`. 버튼을 누르면 그림자가 사라지고 버튼이 3px 내려간다.
- ⚠️ **SF Symbols(애플 기본 아이콘)를 쓰지 않는다.** 픽셀아트가 아니라서 섞이면 어색하다. 필요한 아이콘을 도트로 직접 만든다. 크기는 16 또는 24.

필요한 아이콘: 재생 · 멈춤 · 다음 · 사진 · 자물쇠 · 체크 · 위치핀 · 다운로드 · 홈 · 지도 · 사람 · 뒤로

### 움직임

픽셀아트는 부드럽게 움직이면 어색하다. **단계적으로** 움직인다.

- 전환 100~150ms, 이징은 단계형(step) 또는 선형
- 흐림·번짐 효과 금지
- 캐릭터는 2~3프레임 반복 (숨 쉬는 정도)
- 화면 전환은 슬라이드보다 **즉시 교체**

## 4. 화면 구조 — 탭 4개

| 탭 | 담는 것 | 사용자의 핵심 행동 |
|---|---|---|
| **홈** | 성산 카드(최상단·가장 크게) · 오늘의 추천 코스 | 성산 카드를 눌러 이야기 경험에 진입한다 |
| **스토리** | 이야기가 준비된 장소 목록 (v1은 성산 1개) | 어디에 이야기가 있는지 훑는다 |
| **코스** | 코스 만들기(무료 훅) + 내 코스 | 2단계 질문(지역 → 기간)에 답하고 추천 코스를 받는다 |
| **내 것** | 구매한 이야기 · **구매 복원** · 프로필 · **계정 삭제** | 결제 내역을 관리한다 |

**"내 것" 탭은 필수다.** 애플은 유료 콘텐츠 앱에 구매 복원 경로를, 로그인 있는 앱에 계정 삭제 경로를 요구한다. 없으면 앱스토어 심사에서 거절된다.

**유료 진입점을 코스 추천에 종속시키지 않는다.** 무료 코스는 약 9,000개에서 추천되는데 유료 여정은 1개뿐이라, 추천 결과에 성산이 없으면 사용자가 핵심 기능을 만날 기회 자체가 없다. 그래서 홈 최상단에 독립 진입점을 뒀다.

## 5. 사용자 흐름

```
[집에서]   홈 → 성산 카드 → 여정 소개 화면
           · 이야기 몇 개 / 총 몇 분 / 어디서 시작 / 앞부분 무료 표시
           · [미리 듣기]  [미리 받아두기]
              ↑ 정상은 통신이 불안하다. 시작 전 다운로드를 강하게 권한다.

[현장 도착] 성산 카드에 "지금 여기예요" 배지 → 시작

[걷는 중]   관찰 지점에 도착하면 GPS가 감지해 오디오가 자동 재생된다.
           (자동 재생은 설정에서 끌 수 있고, 어디서든 수동 재생도 된다)

           재생 화면: [재생/멈춤] [참고사진] [다음 지점]  ← 이 셋만.
           눈은 풍경을 봐야 한다.

           각 지점의 이야기 흐름:
           "무엇을 보라" → "왜?" → "숨은 사연" → "이제 다르게 보인다"

[질문 지점] 1~2곳에서 앱이 묻는다. 예: "절벽 아래 검은 구멍들 보이세요? 몇 개쯤?"
           사용자가 말이나 타이핑으로 답하면 세 갈래로 갈린다:
             ① 개수를 말함    → "맞아요. 보이는 건 일부고 실제로는 스물네 개입니다…"
             ② 안 보인다고 함 → "조금 왼쪽을 보세요. 바위 색이 어두운 부분…"
             ③ 딴 얘기를 함   → "그것도 궁금하시죠? 잠깐만요, 먼저 저 절벽부터."
           ③이 반드시 필요하다. 사용자는 예상대로 답하지 않는다.

[무료 끝]   🔒 "여기서부터 결제가 필요해요"
           남은 이야기 N개 · 5,000원 이하 · 90일 이용

[완료]      들은 이야기 기록 화면 (픽셀아트로 꾸미는 구간)
```

**실패해도 여정은 멈추지 않는다.** 통신이 끊기거나 질문 기능이 죽어도 사용자는 성산을 끝까지 걸으며 이야기를 다 들을 수 있어야 한다. GPS가 안 잡히면 수동 재생, 음성 인식이 실패하면 타이핑, 15초 무응답이면 "괜찮아요" 하고 진행.

## 6. 데이터 구조

### 여정 (= 장소 1개 = 유료 상품 1개)

```
제목          "성산일출봉 — 아름다움 뒤의 이야기"
한 줄 소개     "예쁜 사진 뒤에 가려진 것들"          ← 카드에 노출
관통 주제      "가장 아름다운 곳에 가장 아픈 기억이 있다"
총 소요시간    50분
이야기 개수    5
무료 개수      2                                  ← 전체의 30~40%
가격          4,900원
이용 기간      90일
커버 사진      실사 1장
좌표          33.4581, 126.9415
```

**관통 주제가 없으면 이야기 5개는 잡학 5개가 된다.** 마지막에 무엇이 남는지를 결정하는 항목이다.

### 이야기 (= 관찰 지점 1개)

```
① 어디인가       위도·경도 / 트리거 반경 40m
                 찾아가는 말: "계단을 한참 오르면 오른쪽에 우뚝 선 큰 바위가 나옵니다"
                 → GPS 오차가 5~21m라 말로도 위치를 알려줘야 한다

② 무엇이 보이는가  ★ 가장 중요
                 보이는 대상 + 방향. 예: "정면 북동쪽에 우도, 발밑 남서쪽에 분화구"
                 → 대사에서 "저것을 보세요"라고 하려면 실제로 보여야 한다

③ 오디오 대사     60~90초

④ 참고사진        사진 + 그 위에 표시할 것 (대상 위치 → 라벨)
                 → 말로만 짚으면 못 찾는 사용자가 생긴다. 이것이 보험이다

⑤ 무료 여부
⑥ 질문 지점 여부
⑦ 재생 길이(초)
```

**참고사진 마커 규칙:** 실사 사진 위에 픽셀 마커를 올린다. 원은 2px 테두리·채우기 없음·잠김색, 화살표는 8×8 도트 삼각형, 라벨은 표면 배경 + 2px 테두리 박스. **한 사진에 마커는 3개까지** — 그 이상이면 무엇을 봐야 할지 흐려진다.

### 대사 작성 규칙

1. **안내판·검색에 있는 정보는 쓰지 않는다** — "유네스코 세계자연유산", "높이 182m". 이건 유료 가치가 아니다.
2. **알고 나면 눈앞의 것이 달라 보여야 한다.** 사실 전달로 끝내지 않고 다시 보게 만드는 것까지가 하나의 이야기다.

## 7. 지금 만들어진 것 / 아직 없는 것

### 이미 만들어진 화면 (스크린샷 첨부)

| 화면 | 상태 |
|---|---|
| 홈 (성산 카드 + 추천 코스) | 픽셀 적용 완료 |
| 스토리 목록 | 픽셀 적용 완료 |
| 코스 (만들기 / 내 코스 전환) | 상단만 픽셀, 안쪽은 구 디자인 |
| 내 것 (로그인·계정삭제·처리방침) | 픽셀 적용 완료 |
| 다크 모드 | 전 화면 지원 |

이미 만든 컴포넌트: 픽셀 버튼(3종) · 카드 · 배지(무료/지금여기/들었어요/잠김) · 칸으로 나뉜 진행바 · 도트 아이콘 12종.

**진행바는 부드러운 막대가 아니라 칸으로 나뉜 막대다.** 이야기 5개면 칸 5개(`■ ■ ■ □ □`). 몇 개 남았는지가 바로 보인다.

### ★ 디자인이 필요한 화면 (여기가 요청 사항)

| 화면 | 무엇이 담기나 | 주의 |
|---|---|---|
| **① 여정 소개** | 커버 사진 · 관통 주제 · 이야기 개수/총 시간 · 시작 지점 안내 · 무료 범위 표시 · [미리 듣기] [미리 받아두기] | 결제 전 마지막 설득 화면. 화면을 봐도 되는 구간이라 꾸며도 된다 |
| **② 이야기 재생** | [재생/멈춤] [참고사진] [다음 지점] · 상단에 지점 이름 + 칸 진행바 | **요소 3개 초과 금지.** 배경 단색. 캐릭터 띄우지 않는다 |
| **③ 참고사진 뷰어** | 실사 사진 + 픽셀 마커/화살표/라벨 | 사진은 원본 그대로. 마커 최대 3개 |
| **④ 질문 순간** | 질문 텍스트 + 음성 입력 + 타이핑 폴백 | 두 입력 경로를 항상 동시에 제공 |
| **⑤ 잠김 / 결제** | 자물쇠 · "남은 이야기 N개" · 가격 · 90일 · 구매 버튼 | 색 + 자물쇠 모양을 함께 |
| **⑥ 완료 기록** | 들은 이야기 목록 · 걸은 경로 · 픽셀아트 기념 화면 | 가장 자유롭게 꾸며도 되는 화면 |
| **⑦ 가이드 캐릭터** | 정면 기본 / 말하는 중 / 기뻐하는 중, 3종 | 64×64 기준, 투명 배경 PNG, 팔레트 준수 |
| **⑧ 앱 아이콘** | "놀멍봅서" 4글자를 2줄로 쌓는다 | 아래 규칙 참조 |

### 앱 아이콘 규칙 (놓치면 앱스토어 거절)

```
┌─────────┐
│ 놀   멍 │   2줄 = 정사각형을 꽉 채움
│ 봅   서 │   픽셀 폰트는 글자 폭이 일정해 줄이 딱 맞는다
└─────────┘
```

- 1024×1024 (=128×8)
- **투명 배경(알파 채널) 금지** — 배경을 반드시 색으로 채운다
- **모서리를 미리 둥글게 깎지 않는다** — 애플이 자동으로 깎는다. 미리 깎으면 이중으로 깎여 이상해진다. 정사각으로 제출
- 픽셀아트는 모서리가 깎이면 도트가 어긋나 보이므로 **글자를 중앙에 두고 가장자리 여백을 넉넉히**

### 생성 모델을 쓸 때 ⚠️

| 대상 | 가능 여부 |
|---|---|
| 캐릭터·배경 | ⭕ 생성 모델 OK |
| **"놀멍봅서" 글자** | ❌ **갈무리 폰트로 직접 조판.** 이미지 모델은 한글을 제대로 못 쓴다 |

생성 모델은 "픽셀아트처럼 보이는 고해상도 그림"을 만든다. 도트 격자가 정수로 안 맞고, 색이 수백 개 섞이고, 경계가 흐리다. 작게 보면 괜찮지만 아이콘은 1024로 크게 쓰이므로 드러난다. **후처리 필수:**

1. 생성물을 작게 줄인다 (128×128)
2. 색을 위 팔레트로 축소·고정한다
3. **정수배로** 다시 확대한다 (128 × 8 = 1024, 부드럽게 늘리지 말고 계단식으로)
