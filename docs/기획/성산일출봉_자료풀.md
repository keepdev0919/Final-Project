## 1. 지질·자연

- **[관찰]** 켜켜이 쌓인 화산재 지층·깎여나간 절벽 ↔ **[사연]** 약 **5,000년 전** 형성된 "젊은 산". 최근 연구로 **한 번이 아니라 여러 번 분출한 복합화산체(3개 화산 중첩)**로 규명. 원래 더 컸으나 **파도 침식으로 지금 형태**가 됨. **[훅] ②전환**("완성된 산이 아니라 바다가 지금도 깎는 중") + 놀라움

## 2. 역사·군사

- **[관찰]** 병풍처럼 둘러선 **바위 봉우리들** ↔ **[사연]** 이름 **성(城)산** = "석벽이 병풍처럼 둘러 꼭대기가 성처럼 보인다"는 옛 문헌에서. '일출봉'은 영주십경 **성산출일(城山出日)**에서 온 비교적 근래 이름. **[훅] ②전환**(이름의 뜻을 알고 능선을 다시 봄)
  - 출처: 디지털서귀포문화대전 https://seogwipo.grandculture.net/seogwipo/toc/GC04600071 · 위키백과
- **[관찰]** 해안 절벽 아래 **인공 굴 24개** ↔ **[사연]** **1943년 일제**가 태평양전쟁 대비로 절벽에 굴을 파 **자살특공정(쾌속정)·어뢰를 숨김.** 성산리 주민들이 **강제 동원**돼 생계 포기하고 돌을 부쉈고, 이후 많은 주민이 이주. **[훅] ①뭉클/충격 + ②전환**(아름다운 절벽 밑 전쟁의 상흔) — **최상급 후보**
  - 출처: 브런치 https://brunch.co.kr/@u842/196 · 위키백과
- **[관찰]** (숲 없는) 지금의 성산 ↔ **[사연]** 고려 삼별초가 여몽연합군에 맞서 "토성을 쌓았다" 기록 → 당시엔 울창한 숲. 조선 임진왜란 때 군사 요새. **[훅] ②전환** (⚠️확인필요 — 브런치 단일 출처)
  - 출처: 브런치 https://brunch.co.kr/@u842/196
- **후보 테마:** "성이라 불린 산 — 방어의 역사" / "아름다움 뒤의 상처"

## 4. 설화·전설

- **[설화] 99봉 전설** — 성산일출봉 봉우리가 100이었다면 제주에 호랑이·사자 같은 맹수가 났을 텐데, **하나가 모자란 99라 맹수가 안 난다.** **[연결]** 정상 능선의 봉우리들. **[훅] ②전환**(능선을 세어보게 됨) + 재미
  - 출처: 한국민족문화대백과 https://encykorea.aks.ac.kr/Article/E0047331
- **[지명] 광치기 해변의 아픔** — 지명 유래 두 설: (a) "빛이 흠뻑 비친다/썰물에 광야처럼 펼쳐진다", (b) **'관치기' 설: 조정이 (제주인의 육지 도망 방지 위해) 선박 건조를 금함 → 삼나무 토막 뗏목으로 조업 → 풍랑에 빠져 죽은 어부 시신이 해류로 이 해변에 밀려옴 → 성산 주민이 관을 짜 입관해 묻어준 데서 '관치기'→'광치기'.** **[연결]** 광치기해변(성산일출봉 조망 명소). **[훅] ①뭉클 + ②전환** — **최상급 후보**(아름다운 해변 밑 비극). ✅ (b)설은 복수 출처 교차확인됨. 단 여전히 "전해지는 설(說)"이므로 콘텐츠에서 "~라고 전한다"로 처리 권장(단정 금지)
  - 출처: 브런치 https://brunch.co.kr/@u842/196 · 서귀포신문 https://www.seogwipo.co.kr/news/articleView.html?idxno=217615 · 대한민국 구석구석 https://korean.visitkorea.or.kr/detail/rem_detail.do?cotid=e871673d-1764-4c22-b781-8cdabdc4fb4a
- **[지명] 오정개·우묵개** — 성산일출봉 동쪽 해안 지명. 세부 유래 ⚠️추가조사
  - 출처: 한국민족문화대백과
- **로컬 데이터 확인 결과:** `data/extracted/`의 "성산" 언급 62개는 **대부분 성산=행정지역 배경**이고, '일출봉/성산봉' 직접 언급은 `T_M_054.txt`(영감본 무속 본풀이) 1건뿐인데 이마저 성산일출봉 지형과 무관. **→ 성산일출봉 전용 설화는 로컬에 사실상 없음. 웹 수집분(99봉·광치기)이 주력 재료.**

## 5. 감각·현장 관찰 (동선 = 시선 유도의 뼈대)

- **동선:** 매표소 → 계단·나무데크 오르막(약 1km) → 정상 전망대 (20~30분). 왕복+관람 1.5h.
- **오르며:** 꾸준한 오르막, 뒤돌아보면 성산마을·바다 시야 트임.
- **정상:** 눈앞에 **사발 분화구**, 멀리 **우도**, 넓은 바다·하늘, 한라산 방향, 바닷바람·개방감.
- **밖에서 조망:** **광치기해변**에서 성산일출봉 전체 실루엣(특히 일출·썰물 때).
- **팁:** 아침 일찍(붐빔·일출). 계절: 억새·유채.
- **[훅]** 정상 개방감 = ①경이 / 분화구 내려다보기 = ②전환 시선유도 포인트

## 🎯 떠오르는 후보 테마 (아직 결정 아님 — 실물 자료에서 관찰됨)

1. **"아름다움 뒤의 상처"** — 절경(분화구·일출) ↔ 일제 굴·강제동원·광치기 관 이야기. ①뭉클+②전환 강력, 서사 아크에 적합. ⚠️ 무거움 조절 필요.
2. **"바다가 만든 산"** — 수성화산·복합화산체·파도 침식. ②전환·경이. 미스터리(질문 추적)에 적합.
3. **"성(城)이라 불린 산"** — 이름·형상·방어의 역사. ②전환.
4. **"경계의 땅"** — 바다와 육지, 삶과 죽음(해녀·광치기), 밤과 낮(일출). 통합 테마 가능.
