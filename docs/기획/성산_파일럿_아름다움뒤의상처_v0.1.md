## PART 1. 비트 명세 v1 — 재사용 틀 (이게 다음 장소에도 복붙되는 프레임워크)

### 여정 헤더 (콘텐츠 1개 = 여정 1개)
```
여정명 / 장소 / 테마(관통 메시지 1문장) / 렌즈 / 예상 소요 / 비트 수 / 가격(추후)
동선: 비트를 잇는 실제 경로 (지점 순서)
```

### 비트 1개 = 아래 칸들 (모든 칸 다 채울 필욘 없음 — 필요한 것만)
```
[비트 N] 지점명
─ 앵커: GPS(위도,경도) / 트리거 반경(≥21m) / 자기보고 라벨("○○ 도착") / 수동재생 가능
─ 시선 데이터: 이 지점에서 실제로 뭐가 보이나 (스트리트뷰·영상으로 확보)
─ 내레이션 (미리 생성 오디오, guided-looking 도구상자에서 필요한 것만):
   · 시선유도  — "무엇을 보라" (구체적 대상)
   · 호기심갭  — "왜 그럴까?" (답 전에 궁금증)
   · 드러냄    — 숨은 사연 (①감정 + ②전환이 터지는 곳)
   · 재관찰    — 관점 전환 "확인" (매번 다른 방식·문구, 반복금지)
   · (선택)참여 — 사용자에게 짧은 반응/관찰 유도
─ 인라인 트리거: [이미지][효과음][응답대기][다음지점 안내] 등
─ 대화 대비: 예상질문 3~5 + 각 근거사실 (온디맨드 Q&A용)
─ 품질 게이트(통과 못하면 미완성):
   ☐ 감정: 뭉클/경이/놀라움/재미 중 하나라도 실제로 나나?
   ☐ 전환: 알고 나면 '눈앞의 그것'이 다르게 보이나?
   ☐ 대체불가: 검색으로 얻는 '정보'가 아니라 '거기 서서 봐야' 성립하나?
   ☐ TORE: 주제 있나 / 따라가기 쉽나 / 개인적으로 와닿나 / 지루하지 않나
   ☐ 안-반복: 앞 비트와 구조·문구가 겹치지 않나
─ 제작메타: 음성(TTS/성우) · 예상길이(초) · 자료출처 · ⚠️확인필요 항목
```

### 도구상자 원칙 (반복 방지)
- 4박자(시선유도·갭·드러냄·재관찰)는 **법칙이 아니라 도구.** 비트마다 필요한 것만.
- 재관찰은 "문장"이 아니라 "목적" — 사용자가 스스로 발화하게 하거나, 드러냄이 강해 저절로 다시 보게 하거나, 매번 변주.
- 테마(관통 메시지)가 비트들을 하나의 이야기로 묶음 → 똑같은 루프의 반복이 아님.

## PART 2. 실제 채운 파일럿 — "아름다움 뒤의 상처"

**여정명:** 성산, 아름다움 뒤의 이야기
**테마(관통 메시지):** "눈부신 이 절경은, 사실 수많은 이들의 고단한 삶과 죽음 위에 서 있다."
**렌즈:** 역사 + 사람 (설화·지질은 다른 테마로 분리)
**동선:** 광치기해변(조망) → 매표소 → 등경돌 → 정상 전망대 → (하산)
**비트 수:** 4개 (파일럿), 예상 40~50분
> ⚠️ 대사는 톤·구조를 보여주는 **초안 스케치**. 사실·표현 미검증.

---

### [비트 1] 광치기해변 — 여정의 문을 여는 곳
─ **앵커:** 광치기해변(성산읍 고성리 224-33 부근) / 반경 40m / "광치기해변에 도착했어요" / 수동재생 가능
─ **시선 데이터:** 바다 건너 성산일출봉 전체 실루엣이 보임. 절벽 곳곳에 검은 구멍(일제 굴)이 육안으로 보임. 썰물 땐 녹색 이끼 암반 드러남.
─ **내레이션:**
   · 시선유도: "잠깐 멈춰서, 바다 건너 저 거대한 성산일출봉을 정면으로 바라보세요."
   · 호기심갭: "아름답죠. 그런데 절벽 아래쪽, 검은 구멍들이 몇 개 보이시나요? 자연 동굴이 아닙니다."
   · 드러냄: "1943년, 일본군이 주민들을 강제로 동원해 저 절벽에 24개의 굴을 팠습니다. 자살특공정을 숨기려고요. 그리고 지금 발밑 이 해변의 이름은 '광치기' — 풍랑에 목숨을 잃은 뗏목 어부들의 시신이 밀려오면, 주민들이 관을 짜 묻어주던 곳이라 전해집니다." [잔잔한 효과음]
   · 재관찰: (참여로 대체) "이제 다시 저 절벽을 보세요. 방금 전과 같은 풍경인가요?"
─ **인라인 트리거:** [일제 굴 위치 표시 이미지][응답대기]
─ **대화 대비:** "굴을 지금도 들어갈 수 있어요?" / "왜 하필 성산이었어요?" / "광치기 유래가 확실해요?"(→ "여러 설 중 하나로 전해진다" 정직히)
─ **품질 게이트:** 감정☑(뭉클·충격) 전환☑(절경→상처) 대체불가☑(그 절벽 보며) TORE☑ 안반복☑
─ **제작메타:** 성우 후보(감정 절정) · ~90초 · 출처=자료풀 §2,§4 · ⚠️광치기 유래 "설"로 처리

### [비트 2] 매표소~오르막 — 강제 동원의 길
─ **앵커:** 매표소 통과 후 오르막 초입 / 반경 25m / "올라가기 시작했어요"
─ **시선 데이터:** 가파른 계단, 뒤돌아보면 성산마을·바다.
─ **내레이션:**
   · 시선유도: "숨이 차기 시작하죠. 잠깐 뒤를 돌아 마을을 보세요."
   · 드러냄: "80여 년 전, 이 산을 오르내린 건 관광객이 아니라 강제로 끌려온 성산리 주민들이었습니다. 생계를 놓고 돌을 깨야 했고, 많은 이들이 마을을 떠났습니다."
   · 재관찰: (저절로) — 닫는 멘트 없이 다음 지점으로. 발걸음의 무게로 여운.
─ **대화 대비:** "주민들은 어떻게 됐어요?" / "보상은 있었나요?"
─ **품질 게이트:** 감정☑ 전환☑(등산로→강제노역의 길) 대체불가☑ 안반복☑(1번과 달리 닫는 멘트 없음)
─ **제작메타:** TTS · ~50초 · ⚠️ 무게 조절(연속 무거움 주의)

### [비트 3] 등경돌 — 삶은 계속됐다
─ **앵커:** 등경돌 부근 / 반경 25m / "등경돌 지나요"
─ **시선 데이터:** 우뚝 선 등경돌 바위. 아래로 바다·해녀 조업 구역 방향.
─ **내레이션:**
   · 시선유도: "저 우뚝 선 바위, 등경돌입니다. 그리고 그 너머 바다를 보세요."
   · 드러냄: "이 아픈 땅에서도 삶은 이어졌습니다. 저 바다에선 지금도 해녀들이 숨을 참고 물질을 합니다. 2~3분을 잠수하고 올라오며 내쉬는 '숨비소리'로." [숨비소리 효과음]
   · 참여: "지금 바다에 해녀가 보이시나요? 하얀 테왁이 떠 있을지도 몰라요."
─ **대화 대비:** "해녀는 지금도 있어요?" / "등경돌 이름 뜻은?"(⚠️추가조사)
─ **품질 게이트:** 감정☑(경외·뭉클) 전환☑(상처→그 위의 생명력) 대체불가☑ 안반복☑
─ **제작메타:** TTS+숨비소리 · ~60초 · ⚠️등경돌 유래·해녀 실제 조업 위치 확인

### [비트 4] 정상 전망대 — 그래서 이 풍경은
─ **앵커:** 정상 전망대 / 반경 30m / "정상 도착!"
─ **시선 데이터:** 지름 600m 사발 분화구, 우도, 사방 바다·하늘.
─ **내레이션:**
   · 시선유도: "다 오셨습니다. 눈앞의 거대한 분화구, 그리고 저 멀리 소가 누운 듯한 우도까지."
   · 드러냄: "5천 년 전 바닷속 폭발로 솟은 이 산은, 성이라 불리며 누군가를 지켰고, 아프게 팠였고, 그 아래에서 사람들이 살아냈습니다."
   · 재관찰: "처음 광치기에서 봤던 그 풍경과, 지금 이 자리에서 보는 풍경. 같은 성산일출봉이 다르게 느껴지시나요?"
   · 참여: "오늘 이 산에서, 어떤 이야기가 가장 오래 남을 것 같으세요?"
─ **인라인 트리거:** [여정 요약][응답대기]
─ **품질 게이트:** 감정☑ 전환☑(여정 전체 회수) 대체불가☑ TORE☑(테마 완결) 안반복☑
─ **제작메타:** 성우 후보(피날레) · ~80초

## PART 3. 이 파일럿이 검증하려는 것 (틀 확정 체크)

- [ ] 비트 명세 v1 칸들이 실제 채워보니 충분한가 / 과한가?
- [ ] "현장 없이 시선 데이터" — 등반로 바위(처녀바위·등경돌·초관바위·곰바위)·광치기 조망까지 웹으로 확보됨. **각 바위의 생김새·유래는 추가 조사 필요.** (스트리트뷰·영상 다음 단계)
- [ ] 4박자 도구상자 + 반복금지가 실제로 지루함을 막나? (비트1=참여로 닫고, 2=닫지 않고, 4=회수로 닫음 — 변주 시도됨)
- [ ] ①+② 필터 + TORE 게이트가 트리비아를 실제로 걸러내나?
- [ ] 이 틀이 다음 테마("바다가 만든 산" 등)에 복붙 가능한가?

## PART 4. 남은 리스크·다음 단계
- **무게 조절:** "아름다움 뒤의 상처"는 무겁다. 비트 3(생명력)·4(회수)로 반전을 줬지만, 실제 정서 곡선은 현장·사용자 검증 필요.
- **사실 검증:** 등경돌 유래, 해녀 실제 조업 위치, 일제 굴 관람 가능 범위 등 ⚠️ 항목.
- **시선 데이터 정밀화:** 지점별 스트리트뷰/1인칭 영상으로 "정확히 뭐가 어느 방향에 보이나" 확정.
- **다음:** 이 틀 승인 → 나머지 테마(바다가 만든 산 / 성이라 불린 산 / 경계의 땅) 서브에이전트 병렬 제작.
