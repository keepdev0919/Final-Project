**용도:** 어떤 제주 장소를 어떤 순서로 콘텐츠화할지. "성산 완성 → 다음 뭐?"의 기준 문서.

## 선정 기준 (다음 장소를 고를 때)

리서치(O-Mopsi 콘텐츠 품질 원칙) + 우리 전략 반영:

1. **관찰 재료 밀도** — "눈에 보이는 것 + 숨은 맥락"이 풍부한가 (guided-looking의 재료).
2. **이야기·맥락 깊이** — 역사·설화·지질·사람 이야기가 층층이 있는가.
3. **방문 수요** — 관광객이 실제로 많이 가는가 (단건 결제 수요 = 매출).
4. **현장 특정성** — 현장에서만 성립하는 경험인가 (해자가 서는가).
5. **원격 저작 가능성** — 스트리트뷰·자료·영상으로 설계 가능한가 (개발자 서울 거주 제약).
6. **제주 특화·차별성** — 공모전 가점 + 다른 장소와 겹치지 않는 유일성.

## 장소 하나가 거치는 제작 파이프라인

```
① 선정 (기준 통과)
   ↓
② 자료 조사 (관찰 재료 + 숨은 맥락 수집: 지질·역사·설화·사람·스트리트뷰·사진)
   ↓
③ 비트 설계 (비트 명세 템플릿에 관찰 지점들 채우기)
   ↓
④ 콘텐츠 작성 (대사·시선 유도·페이오프)
   ↓
⑤ 현장 검증 (제주 현장 1회 — 해자·완성도 최종 확인)
   ↓
⑥ 출시 (단건 결제 콘텐츠로)
```

*성산일출봉이 이 파이프라인을 처음 통과하며 각 단계의 "제작 규격"을 정립한다 → 이후 장소는 이 규격을 재사용.*
