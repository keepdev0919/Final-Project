## 6. 중요한 해석

1. **tid = 관광지**라고 단정하지 않는다. tid는 이 원본에서 확인되는 상위 콘텐츠 묶음이다.
2. 같은 tid가 실제 한 관광지인 경우(관음사·약천사·성읍)에는 그 묶음을 적극 활용한다.
3. 한 tid가 여러 독립 장소를 묶은 편집형 콘텐츠라면 그대로 하나의 플레이로 만들지 않는다.
4. 단일 story도 제주목관아처럼 대본 내부 현실 대상이 많으면 강한 후보가 될 수 있다.
5. 따라서 최종 제작 단위는 ID나 거리로 자동 결정하지 않고 **'한 관광지 안에서 3~5개의 관찰→발견→의미가 자연스럽게 이어지는가'**로 결정한다.
6. 좌표는 최종 후보의 실제 보행 동선 검증 단계에서만 사용한다.
