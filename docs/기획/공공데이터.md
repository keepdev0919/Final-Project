## 1. 제주학연구센터 아카이브 · 발간물 ⭐ TOP 1

**URL:** http://www.jst.re.kr/
**아카이브 상세:** http://www.jst.re.kr/jejustudiesDBList.do
**제공기관:** 제주학연구센터

### 기본 정보

| 항목 | 값 |
|---|---|
| 콘텐츠 성격 | 제주 고유 신화·본풀이·구술 생애사·세시풍속·마을 이야기 채록 |
| 데이터 규모 | 아카이브 DB 내 수천 건 · 발간 단행본 수십 편 |
| 1건당 분량 | **1,000~5,000자 (초장문 구어체 대본)** |
| 접근 방식 | 웹 아카이브 검색 + PDF 다운로드 |
| 인증 | 무료 · 로그인 불필요 |
| 라이선스 | **공공누리 제1유형 (출처 표시)** |

### 콘텐츠 표본

> "다들 집으로 돌아갑서. 헤어지는 마당에 서러운 것은 이 한 목숨 아깝지 않으나, 저 불국 잡귀들을 다 잡아 죽이지 못한 것이 한이 될 뿐이우다."

**품질 특징:** 방언·구어체가 살아있음. 오디·젠트립이 흉내 못 내는 톤. RAG 스토리텔링 품질을 압도적으로 견인.

### 활용 전략

- **원자재 위치:** Sprint 1 콘텐츠의 40% (마을 설화·해녀 구술 등 감성 가이드)
- **커버 예상:** 40개소
- **처리 파이프라인:** PDF 다운로드 → OCR → 방언 → 표준어 병기 → 1,000자 톤 통일 → RAG 임베딩

### 주의사항

- 방언 어휘가 다수 섞여 있어 **표준어 병기 리라이팅 필수**
- LLM 프롬프트 예시: "제주 방언은 각주로 남기고, 본문은 표준어 전문 가이드 톤으로 1,000자 이내 재구성"
- 발간물 내 외부 사진 작가 촬영 이미지는 공공누리 범위 밖 (텍스트만 사용)

**URL:** https://www.data.go.kr/data/15101971/openapi.do
**제공기관:** 한국관광공사 (AI인프라센터, 070-4287-3219)
**연관 서비스:** https://www.odii.kr

### 기본 정보

| 항목 | 값 |
|---|---|
| API 유형 | REST (JSON+XML) |
| 트래픽 | 개발계정 1,000회/일 |
| 활용신청 실적 | **675건 (인기 API, 다른 팀도 다 씀)** |
| 라이선스 | 공공누리 제1유형 |
| 상업적 활용 | ✅ 허용 |

### API 목록 (Swagger 확인)

- `/themeBasedList` — 관광지 기본 정보 목록
- `/themeLocationBasedList` — **관광지 위치기반 정보** ← 제주 좌표 조회
- `/themeSearchList` — 관광지 키워드 검색
- `/storyLocationBasedList` — **이야기 위치기반 정보**
- `/storySearchList` — 이야기 키워드 검색
- `/themeBasedSyncList` — 관광지 동기화
- `/storyBasedSyncList` — 이야기 동기화
- `/storyBasedList` — 이야기 기본 정보

### 활용 전략 (수정됨)

- **역할 재정의:** TOP 5가 아닌 **보조 크로스 체크용**. 이유: 다른 팀도 다 쓰는 데이터라 차별화 안 됨.
- **활용 방식:**
  1. TOP 5 소스 정제 후 오디 API로 크로스 체크 (같은 장소 대본 비교)
  2. TOP 5에 없는 관광지가 오디에는 있는지 확인 (커버리지 확장)
  3. 다국어 필드 재활용 (Sprint 3+ 외국인 확장)

### 진행 상태

- ✅ **2026-07-14 활용신청 완료** (개발계정 자동승인 예정)
- 승인 즉시 제주 좌표 조회 → 커버리지 확인

## 데이터 활용 원칙 (판단 흔들릴 때 여기 돌아옴)

1. **원자재 재활용 ≠ 재생 서비스.** 공공 데이터를 "그대로 재생"하면 오디 카피. 우리는 **재가공(톤 통일 · 쌍방향 인터랙션 · 게임화)**으로 차별화.
2. **라이선스 먼저 확인, 크레딧 명시.** 공공누리 제1유형은 출처 표시 필수. 앱 내 "출처: 제주학연구센터" 등 명시.
3. **로컬 캐시 + 서버 프록시.** 공공 API 트래픽 제한 대응. 사용자 단말이 직접 호출하지 않음.
4. **콘텐츠 톤 리라이팅은 Sprint 1 스코프 포함.** 원본 톤이 안내문 · 방언·학술 톤이면 우리 "전문 가이드" 톤으로 리라이팅.
5. **경쟁 팀도 같은 데이터 씀을 전제.** 데이터 자체는 해자가 아님. 해자는 **데이터 × 인터랙션 × BM**.
6. **저작권 확인 3단 필터.** (a) 공공누리 유형 (b) 개별 마크 (c) 외부 기증 저작물 제외.
7. **Sprint 1에서 위험 소스 폴더 물리적 분리.** 우발적 학습 데이터 혼입 방지.
