## 3. "완성 서비스" 요건 ★자격

- 미완성·기획안 불가. **한국관광공사 OpenAPI 필수 활용 + 개발 완료된 완성 서비스에 한정하여 심사.**
- **앱 = 구글 플레이·애플 앱스토어·원스토어 중 최소 1개 등록 완료 후 URL 제출.** 스토어 등록 기간 역산 필요, **추가 개발기간 없음.**
- 웹/앱/SW 등 형태는 심사에 영향 없음. 두 종 이상 개발 시 **동일 내용의 서비스**여야 함.
- 생성형 AI 코딩 도구 활용 제한·감점 없음. 핵심 = "안정 구동 완제품".
- **중복 출품 금지:** 타 부문(생성형 AI 활용 프롬프트 부문 / 웹 구현 부문)에 동일 서비스로 지원 불가. 확인 시 **심사 제외 및 수상 취소.**
- 동일 서비스로 본 공모전 수상 또는 공사 주관 지원사업(서비스 개발·구축 지원) 수혜 시 심사 제외.

### 4-2. 서비스 테스트 정보 ★사전 준비 필요
- **앱:** 구글/애플/원스토어 중 1개 스토어 등록 URL. **웹:** 접속 가능한 웹사이트 URL.
- **로그인 방식 4유형 중 해당 항목 선택·기재:**
  1. 로그인 불필요 (테스트 계정 생성 불필요)
  2. 별도 로그인 필요 (ID/PW) — 서비스 이용·테스트 가능한 계정 제공
  3. SNS 연동 로그인 (구글·카카오·네이버 등, 테스트 계정 생성 불필요)
  4. 별도 계정 생성하여 로그인 — **지정 형태로 생성** (예: 일반계정 `ID: openapi` / 이메일계정 `openapi@…`) ⚠️ PW 예시 문구 판독 불확실
- ⚠️ **개인 계정 제출 불가.** 반드시 지정된 형태의 ID/PW를 새로 생성.
- **로그인이 안 되면 서비스 확인 불가 → 심사 제외.**
- → **탐라담 현재 Google Sign-In 사용 중** = 유형 3 해당 가능하나, 심사위원 확인 실패 리스크 있음. **심사용 별도 ID/PW 로그인 경로 마련 검토 필요.**

### 4-3. KTO OpenAPI 활용 정보 ★사전 준비 필요
- 제출 시 **인증키(인코딩/디코딩)** 등 제출. **활용 API별로 서비스 개발 기간 내 호출 이력이 있어야 하며, API 활용 내역을 확인할 예정.**
- ⚠️ **대표 1개 API에 대한 운영계정 신청** 관련 문구 존재 — **"필수"인지 "선택"인지 판독 불확실. 반드시 원문/운영사무국 확인.** (요건이면 신청 리드타임 필요 → 최우선 확인 항목)
- 인정 기준: **실시간 호출(OpenAPI 형태)만 인정** — 파일/맞춤형 다운로드 활용 불인정. 개수 하한 없음("하나 이상").
- 원천 데이터 가공·캐싱 저장 가능(FAQ에 "로컬 DB 저장·캐싱 가능 여부" 항목 존재). 원천 변형 시 분쟁 책임은 개발자.
- 저작권: 소유권은 참가자. 단 **"한국관광공사/KTO" 명칭·로고 사용 금지** (FAQ에 출처 표기와의 충돌 관련 항목 존재).
- 트래픽: 개발계정 일 1,000건/오퍼레이션, 운영계정 일 100,000건. 서비스키 유효 2년.
