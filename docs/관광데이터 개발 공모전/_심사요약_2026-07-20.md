## 2. 심사 방식
- **1차 = 비발표**, 서면+기능심사(완성 서비스 대상) [OT p.10,12]
- **최종 = 발표심사**, PPT 필수, ②-2 부문과 통합 [OT p.13]. 온·오프라인 명시 없음(추후 공지)

## 3. "완성 서비스" 요건 [OT p.10,12,19,20]
- 미완성·기획안 불가. **앱 = 구글·애플·원스토어 중 최소 1개 등록·승인 완료 링크 제출 필수.** 스토어 심사기간 역산 필요, **추가 개발기간 없음.** ← iOS 탐라담 최대 리스크
- 제출: 팀정보·서비스정보(지역특화 여부)·테스트 정보(앱=스토어 링크)·OpenAPI 활용정보(API명·운영계정·인증키)·기능설명서(양식 추후)
- 웹/앱 형태는 심사 무관. 생성형 AI(챗봇/RAG/에이전트)·AI 코딩툴 감점·제한 없음. 핵심 = "안정 구동 완제품" [OT p.19]

## 4. OpenAPI 활용 요건 ★필수 [OT p.16,18 / API p.3,43]
- **KTO OpenAPI 필수 활용, 미활용 시 심사 제외.** **실시간 호출(OpenAPI 형태)만 인정 — 파일/맞춤형 다운로드 활용 불인정.** 개수 하한 없음("하나 이상")
- 인정 판정 = 호출 내역 + 서비스 내 활용 확인. 운영계정 신청정보·인증키 제출, 기능설명서에 활용 기재
- 원천 데이터 가공 저장 가능하나 원천 변형 시 분쟁책임 개발자 [API p.43]
- 저작권: 소유권 참가자. 단 "한국관광공사/KTO" 명칭·로고 사용 금지 [OT p.22]
- 트래픽: 개발계정 일 1,000건/오퍼레이션, 운영계정 일 100,000건. 서비스키 유효 2년 [API p.8,29,41]

## 7. OpenAPI — 탐라담 유용 포인트 [API]
- 보유: 약 458만 건. 국문 관광정보 264,396 · 관광사진 187,604 · **관광지오디오 69,585** · 빅데이터 194만 [API p.1,6]. iOS 활용 앱 희소(안드로 44.7% 최다) → 차별화 기회
- **위치기반 조회(locationBasedList): GPS 경위도+반경, 최대 20km** [API p.4,5] ← 성산 현장 앵커링 직결
- 상세 = 4개 API 조합(공통정보=이미지·좌표·개요 / 소개·반복정보 / 이미지정보) [API p.27,36,37]
- **관광지 오디오 가이드 API**(오디오 목록·위치기반 이야기·키워드), 두루누비(코스), 관광빅데이터(방문자·집중률), 행사·숙박·반려동물 등
- contentTypeId 필수(관광지12·문화14·행사15·코스25·레포츠28·숙박32·쇼핑38·음식39) [API p.34,36]. 분류: 지역>시군구>서비스분류(대>중>소, 산/오름/봉우리 존재)
- ⚠ 26년 폐기 예정: "지역코드조회"·"서비스 분류코드 조회" — 신규 체계 전환 [API p.5]
- ⚠ **위치정보 수집 → 위치기반서비스사업 신고 대상 여부 사전 검토** [API p.42]
