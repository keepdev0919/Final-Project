놀멍봅서(이하 "서비스")는 이용자의 개인정보를 중요하게 생각하며, 아래와 같이 처리합니다.

## 1. 수집하는 정보

| 항목 | 수집 시점 | 목적 | 보관 기간 |
|---|---|---|---|
| 이메일, 소셜 로그인 식별자 | 로그인할 때 | 계정 식별, 기기 간 데이터 동기화 | 계정 삭제 시까지 |
| 저장한 여행 코스 | 이용자가 코스를 저장할 때 | 서비스 제공, 기기 간 동기화 | 계정 삭제 시까지 |
| 작성한 장소 리뷰 (태그·메모) | 이용자가 리뷰를 작성할 때 | 서비스 제공 | 계정 삭제 시까지 |
| 기기 식별자 | 리뷰를 작성할 때 | 로그인 없이 작성한 리뷰를 이용자와 연결 | 계정 삭제 시까지 |
| 음성 | 음성 입력 기능을 사용할 때 | 말한 내용을 글자로 변환 | 서비스는 **저장하지 않음**. 변환은 Apple 음성 인식이 수행 (아래 3항) |

**기기 식별자는 앱이 자체적으로 만든 무작위 값**이며, 앱을 삭제하면 사라집니다. 광고 식별자(IDFA)나 기기 고유번호를 수집하지 않습니다.

### 수집하지 않는 것

- 이름, 생년월일, 성별, 전화번호
- 결제 정보 — **애플 인앱결제**를 이용하므로 카드 정보 등은 애플이 처리하며 서비스는 접근할 수 없습니다
- 광고 식별자, 연락처, 사진첩, 캘런더

## 2. 위치 정보

> **위치 정보는 이용자의 기기 안에서만 사용하며, 서비스의 서버로 전송하거나 저장하지 않습니다.**

관광지에 도착했을 때 준비된 이야기를 안내하기 위해 기기의 GPS를 사용합니다. **도착 여부 판단은 기기 내부에서 좌표를 비교하는 방식으로만** 이루어지며, 그 결과나 위치 값이 외부로 나가지 않습니다.

화면이 꺼져 있거나 앱이 백그라운드일 때도 도착을 감지하기 위해 위치 접근 권한이 필요합니다. 위치 사용을 원하지 않으시면 iOS 설정에서 권한을 끌 수 있으며, 이 경우 이야기를 직접 눌러 재생하실 수 있습니다.

## 3. 제3자 제공 및 처리 위탁

수집한 개인정보를 제3자에게 판매하거나 제공하지 않습니다. 서비스 운영을 위해 아래 처리 위탁을 이용합니다.

| 수탁자 | 위탁 업무 | 이전되는 정보 |
|---|---|---|
| Google (Firebase) | 계정 인증, 데이터 저장 | 이메일, 소셜 로그인 식별자, 저장한 코스 |
| OpenAI | 음성 합성, 텍스트 처리 | 처리에 필요한 텍스트 (개인 식별 정보 미포함) |
| Apple | 인앱결제 처리 | 결제 정보 (서비스는 접근하지 않음) |
| Apple | **음성 인식** (말한 내용을 글자로 변환) | 음성 데이터 |

**음성 인식은 Apple의 서버에서 처리됩니다.** iOS가 제공하는 음성 인식 기능을 사용하며, 이 과정에서 음성이 Apple로 전송됩니다. 서비스는 변환된 글자만 받아 쓰고 음성을 저장하지 않습니다. Apple의 음성 데이터 처리는 [Apple 개인정보 정책](https://www.apple.com/legal/privacy/)을 따릅니다.

관광지 정보는 **한국관광공사 OpenAPI**에서 조회합니다. 이 과정에서 관광지의 좌표만 전송하며, **이용자의 개인정보나 위치는 전송하지 않습니다.**

## 4. 이용자의 권리와 행사 방법

| 권리 | 행사 방법 |
|---|---|
| 계정 및 데이터 삭제 | 앱 내 **프로필 → 계정 삭제** |
| 위치 권한 철회 | iOS 설정 → 놀멍봅서 → 위치 |
| 마이크·음성 인식 권한 철회 | iOS 설정 → 놀멍봅서 |

**계정 삭제 시 저장한 코스, 작성한 리뷰, 계정 정보가 모두 삭제되며 복구할 수 없습니다.** 로그인 전에 작성한 리뷰도 함께 삭제됩니다.
