# 개인정보 처리방침 — 정본 위치 안내

**정본은 `backend/static/privacy.html` 이다.** 이 파일에는 본문을 두지 않는다.

서비스가 실제로 게시하는 주소:

```
https://<배포 주소>/privacy
```

라우트는 `backend/routers/legal.py`, 앱 안의 링크는
`ios/JejuFolklore/Sources/Views/ProfileTabView.swift`가 `Config.baseURL + "/privacy"`로 만든다.
따라서 배포처가 바뀌어도 앱 링크는 따라간다.

## 왜 md 본문을 없앴나 (2026-09-09)

앱스토어와 공모전이 **접속 가능한 URL**을 요구하므로 어차피 HTML이 있어야 했다.
md와 HTML 양쪽에 본문을 두면 한쪽만 고쳐져 어긋난다 — 실제로 이전 md 본문은
앱 현황과 세 군데가 달랐다.

| 이전 md의 서술 | 실제 |
|---|---|
| 장소 리뷰·기기 식별자·음성을 수집 | 리뷰 화면에 진입 경로가 없어 **수집하지 않는다** |
| 애플 인앱결제로 결제 처리 | **결제 기능이 없다** (StoreKit 미사용) |
| OpenAI가 음성 합성을 수행 | 음성 합성은 **Typecast**. OpenAI는 오프라인 임베딩 스크립트에서만 쓰고 요청 경로에 없다 |
| 백그라운드에서 도착 감지 | 스토어 심사 대비로 **일반 위치 권한으로 낮췄다**(2026-09-09) |
