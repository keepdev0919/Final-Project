# 문서 뷰어

`docs/` 안의 마크다운을 브라우저에서 읽기 좋게 보는 **로컬 전용** 도구.
앱 기능이 아니고 공모전 제출물도 아니다. 문서를 편하게 보려고 만든 작업 도구다.

## 쓰는 법

```
scripts/docs_viewer/문서보기.command   ← 더블클릭
```

꺼져 있으면 켜고, 켜져 있으면 브라우저만 연다. 몇 번 눌러도 안전하다.
주소는 <http://localhost:4321>.

| 조작 | |
|---|---|
| `⌘K` | 검색창으로 이동 |
| `Esc` | 검색 지우고 원래 문서로 |
| 우상단 버튼 | 시스템 → 밝게 → 어둡게 순환 |
| `#?q=검색어` | 자주 쓰는 검색을 즐겨찾기로 저장 |

끄기: `pkill -f docs_viewer/server.py`

## 설계에서 지킨 것

**미리 HTML을 만들어두지 않는다.** 요청이 올 때마다 디스크에서 md를 읽는다.
미리 생성해두면 문서를 고친 뒤 옛날 내용을 보게 되는데, 그 실패는 조용해서
알아채기 어렵다(지난 마감일을 보고 안심하는 식). 서버가 꺼지면 화면이 아예
안 뜨므로 실패가 시끄럽다. 그쪽이 안전하다.

**표준 라이브러리만 쓴다.** `.venv`를 다시 만들거나 백엔드 의존성이 바뀌어도
문서는 열려야 한다. 환경을 갈아엎을 때가 문서를 가장 자주 찾는 때다.

**127.0.0.1에만 묶는다.** `docs/` 안에 공모전 전략과 미발표 기획이 있다.
같은 와이파이의 다른 기기에서도 접근할 수 없다.

**열람 범위는 화이트리스트.** 실제로 수집된 `.md` 목록과 대조해서 통과시킨다.
`../.env` 같은 요청이 문자열 우회로 뚫리지 않는다.

위 네 가지는 `tests/test_docs_viewer.py`가 지킨다. 바꾸려면 테스트가 먼저 막는다.

**디자인은 앱의 픽셀 토큰을 따른다.** 색·여백·테두리·폰트를 `ios/…/DesignSystem/` 에서 가져왔다.
별도 디자인 문서를 만들지 않았다. 본문이 읽기 폰트인 것도 디자인 규칙 규칙이다
("긴 글은 픽셀 폰트를 쓰지 않는다").

## 자동 시작이 안 되는 이유

프로젝트가 **데스크탑 폴더 안**에 있어서다. macOS는 로그인 시 자동 실행되는
프로그램이 데스크탑을 읽는 걸 차단한다(`Operation not permitted`).
그래서 더블클릭 방식을 쓴다.

자동 시작을 원하면 프로젝트를 데스크탑 밖(`~/dev/놀멍봅서` 등)으로 옮긴 뒤
`./install_autostart.sh`를 실행한다. 자세한 건 그 스크립트가 안내한다.

## 파일

| | |
|---|---|
| `server.py` | 서버. 표준 라이브러리만 |
| `static/style.css` | 앱 픽셀 토큰을 옮긴 스타일 |
| `static/app.js` | 목록·검색·라우팅 |
| `static/vendor/` | 마크다운 변환기, 갈무리 폰트 (오프라인 동작용) |
| `문서보기.command` | 더블클릭 진입점 |
| `install_autostart.sh` | 데스크탑 밖으로 옮겼을 때 쓰는 자동 시작 등록 |
