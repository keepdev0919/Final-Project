# 앱 아이콘 원본

`appicon-original-1024.png` — 생성 원본. 흰 둥근 카드와 회색 여백이 포함된 상태.

실제 아이콘은 이 원본에서 캐릭터 실루엣만 추출해
`ios/JejuFolklore/Resources/Assets.xcassets/AppIcon.appiconset/` 에 세 변형으로 넣었다.

| 변형 | 배경 | 비고 |
|---|---|---|
| `AppIcon-1024.png` | 흰색 꽉 채움 | 알파 채널 없어야 App Store Connect 통과 |
| `AppIcon-1024-dark.png` | 투명 | iOS 18 다크 모드. 시스템이 배경을 깔아준다 |
| `AppIcon-1024-tinted.png` | 투명 + 흑백 | iOS 18 틴티드. 색조가 씌워지므로 명암 대비가 필요 |

## 왜 이렇게 했나

iOS 가 아이콘에 둥근 모서리를 자동으로 씌운다. 원본처럼 흰 둥근 카드를 그려 넣으면
라운드가 이중으로 겹치고 바깥 회색 여백이 액자 테두리처럼 남는다.
그래서 배경은 모서리까지 단색으로 채우고, 캐릭터를 캔버스의 82% 로 키웠다 (원본은 63%).

파일명을 영문으로 두는 이유: macOS 는 한글 파일명을 자모 분리 형태로 저장하는데
빌드 도구·Git·CI 가 합쳐진 형태로 찾으면 파일을 못 찾는다.
